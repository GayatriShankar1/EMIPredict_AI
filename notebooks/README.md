# 💳 EMI Eligibility & Loan Capacity Predictor

An end-to-end Machine Learning web application that predicts a loan applicant's **EMI Eligibility** (Classification) and **Maximum Monthly EMI Capacity** (Regression) based on financial metrics.

## 🚀 Features
- **Data Preprocessing & Feature Engineering**: Automated handling of missing values, encoding, and financial metric generation (DTI ratio, disposable income).
- **Dual ML Models**:
  - **Random Forest Classifier**: Evaluates risk and eligibility (~94% Accuracy).
  - **Random Forest Regressor**: Estimates maximum safe EMI amount (~99% R² Score).
- **Interactive UI**: Real-time Streamlit dashboard for instant financial risk assessment.
